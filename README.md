# Task1-data-immersion-wrangling
Task1 - Data cleaning, data preparation, and data dictionary creation.

## Project Overview
This task focuses on understanding the dataset and preparing it for analysis. 
Data immersion involves exploring the structure and contents of the dataset, 
while data wrangling focuses on cleaning and transforming the data to make it suitable for analysis.

## Objectives
- Understand the dataset and its attributes
- Identify missing or inconsistent data
- Clean and transform the dataset
- Prepare the data for further analysis

## Steps Performed

### 1. Data Exploration
The dataset was initially explored to understand the columns, data types, and structure of the data.

### 2. Data Cleaning
Several data cleaning operations were performed, including:
- Handling missing values
- Removing duplicate records
- Correcting inconsistent data entries

### 3. Data Transformation
Data transformation techniques were applied to ensure the dataset is structured and ready for analysis.

### 4. Data Validation
After cleaning and transformation, the dataset was validated to ensure accuracy and consistency.

## Tools Used
- Excel
- SQL

## Outcome
After completing data immersion and wrangling, the dataset became clean, structured, and ready for exploratory data analysis and visualization.
